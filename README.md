# vh_SSOT

Главный источник фактов проекта VibeHunt. Obsidian и Notion только копии, синхронизация из git в копии.

Начните здесь. Страница объясняет, как читать пометки в файлах и как устроены папки.

## Охват: что описано подробно, что нет

Подробно описан только старт MVP: система в целом (`TOTL`), направления `RECR` и `VIBE`, продукт `TEAM-01`. Решение Owner, 04.10.2026.

Вне MVP описано кратко, подробности не определены намеренно: `AIBOT`, `WAIBO` и остальной `TEAM`. Продукты `TEAM` кроме `TEAM-01` и `AIBOT` не названы, цены и платность `WAIBO` не решены. Это не ошибка описания: решений по ним ещё нет.

## Логика папок

Имя папки: `код - название`, как у файлов. Три уровня:
1. Верхний: `REPO`, `TOTL`, `ARCH` (описание репозитория, системы, архитектуры) и `B2B`, `B2C` (продукты для компаний и для людей).
2. В `B2B` и `B2C`: дивизионы (`RECR`, `VIBE` и так далее), внутри дивизиона папки продуктов (`RECR-01`…).
3. В `REPO`, `TOTL`, `ARCH`: папки разделов (`TOTL-01`…), внутри файлы групп.

В каждой папке лежит обзор с кодом `-00-00-00-0`. Правила: [REPO-01-01-00-0 - Нейминг и структура](REPO%20-%20%D0%9F%D1%80%D0%B0%D0%B2%D0%B8%D0%BB%D0%B0%20%D1%80%D0%B5%D0%BF%D0%BE%D0%B7%D0%B8%D1%82%D0%BE%D1%80%D0%B8%D1%8F/REPO-01%20-%20%D0%9F%D1%80%D0%B0%D0%B2%D0%B8%D0%BB%D0%B0/REPO-01-01-00-0%20-%20%D0%9D%D0%B5%D0%B9%D0%BC%D0%B8%D0%BD%D0%B3%20%D0%B8%20%D1%81%D1%82%D1%80%D1%83%D0%BA%D1%82%D1%83%D1%80%D0%B0.md).
