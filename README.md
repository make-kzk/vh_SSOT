# vh_SSOT

Главный источник фактов проекта VibeHunt. Obsidian и Notion только копии, синхронизация из git в копии.

## Что здесь лежит

| Файл | Что внутри |
|---|---|
| [product.md](product.md) | суть проекта: что делает сервис, для кого, зачем |
| [roles.md](roles.md) | роли в сервисе: HR, Кандидат, Админ (сервис) |
| [processes/README.md](processes/README.md) | десять процессов сервиса: вход, выход, роли |
| [processes/03-profil-kandidata.md](processes/03-profil-kandidata.md) | процесс 3 и его три подпроцесса |
| [sources.md](sources.md) | откуда взяты факты, расхождения между источниками, что не сверено |

## Правила

- Один факт лежит в одном месте.
- У каждого утверждения есть источник. Если источника нет, утверждение помечено «не подтверждено».
- Статус файла в начале: `черновик` или `проверено`. Статус `проверено` ставит человек.
- Здесь только русский язык и без длинных тире.
