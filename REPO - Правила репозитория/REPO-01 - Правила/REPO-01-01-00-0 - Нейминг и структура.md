# REPO-01-01-00-0 - Нейминг и структура

## Формат кода

```
RECR-03-02-00-0 - Оценка вопросов
 │    │  │  │  └── чанк (0 - общая структура)
 │    │  │  └───── документ (00 - обзор уровня)
 │    │  └──────── группа
 │    └─────────── раздел
 └──────────────── дивизион
```

Решение Owner, 03.10.2026.

## Как применяется в этом репозитории

- Имя файла: `код - название.md`, дефис с пробелами. Заголовок файла совпадает с именем.
- Исключения: `README.md` и `Словарь.md` в корне, `README.md` в папке `TOTL` и в папке продукта `VIBE-01` без кода. GitHub показывает README как главную страницу папки.
- `B2B` и `B2C` только папки, не часть кода файла. Решение Owner, 03.10.2026.
- Папки: имя `код - название`, как у файлов. Верхний уровень: `REPO`, `TOTL`, `ARCH`, `B2B`, `B2C`. В `B2B` и `B2C` дивизионы, внутри дивизиона папки продуктов. В `REPO`, `TOTL`, `ARCH` папки разделов. В каждой папке лежит обзор с кодом `-00-00-00-0`.
- Документ `00` описывает уровень целиком: у раздела, у группы, у продукта.

## Как читать код

- Дивизион задаёт область: `TOTL` система, `RECR` продукты для рекрутинга, `VIBE` продукты для людей.
- В `RECR` и `VIBE` раздел это номер продукта.
- Группа это тема внутри продукта. Состав групп определяет Owner для каждого продукта: например, у `RECR-03` две группы (подготовка вопросов, оценка вопросов), у `RECR-05` две группы (тестовое задание, оценка задания).
- Документ это элемент группы. Документ `00` описывает уровень целиком.
- Чанк `0` общая структура документа.
