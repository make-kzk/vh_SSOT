# RECR-00-00-00-0 - Продукты для рекрутинга

Назначение папки: даёт общую картину продуктов рекрутинг. Дивизион `RECR`: продукты для рекрутинга, то есть для компаний. Папка каждого продукта `RECR-0N` даёт точную картину этого продукта. Номер раздела это номер продукта.
Источник: Максим, сообщение от 03.10.2026.

| Код | Продукт | Что делает |
|---|---|---|
| [RECR-01](RECR-01/RECR-01-00-00-0%20-%20Recruiting%20vacancy.md) | Recruiting vacancy | помогает сформировать вакансию и избежать противоречий в ожиданиях |
| [RECR-02](RECR-02/RECR-02-00-00-0%20-%20Recruiting%20match.md) | Recruiting match | помогает подобрать 3 наиболее соответствующих кандидатов |
| [RECR-03](RECR-03/RECR-03-00-00-0%20-%20Recruiting%20interview.md) | Recruiting interview | помогает провести интервью |
| [RECR-04](RECR-04/RECR-04-00-00-0%20-%20Recruiting%20predictive.md) | Recruiting predictive | помогает оценить результативность кандидата до выхода на работу |
| [RECR-05](RECR-05/RECR-05-00-00-0%20-%20Recruiting%20offer.md) | Recruiting offer | помогает сформировать оффер |
| [RECR-06](RECR-06/RECR-06-00-00-0%20-%20Recruiting%20adaptation.md) | Recruiting adaptation | помогает сформировать план адаптации |

В каждом продукте группа `01` это суть, группа `02` процессы. Дальше будут другие группы.
