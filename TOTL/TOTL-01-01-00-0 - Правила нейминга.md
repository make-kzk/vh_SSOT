# TOTL-01-01-00-0 - Правила нейминга

## Формат

```
METD-01-01-00-0 — ABCD Драйверы
 │    │  │  │  └── чанк (0 — общая структура)
 │    │  │  └───── документ (00 — обзор уровня)
 │    │  └──────── группа
 │    └─────────── раздел
 └──────────────── дивизион
```

Источник: Максим, `context-handoff-2026-10.md`, раздел «Правила нейминга».

## Как применяется в этом репозитории

- Имя файла: `код - название.md`, дефис с пробелами, как в Obsidian vh84. Заголовок файла совпадает с именем.
- Исключение: `README.md` и `Словарь.md` в корне без кода (README нужен GitHub, словарь общий для всего репозитория). `README.md` в корне остаётся им, потому что GitHub показывает его как главную страницу. Обзор системы это `TOTL-00-00-00-0`. В папке `TOTL` есть ещё `README.md`: он объясняет общую картину системы, а список файлов остаётся в `TOTL-00-00-00-0`.
- `B2B` и `B2C` только папки, не часть кода файла. Подтверждено Максимом 03.10.2026.
- Папки по структуре: `TOTL`, `B2B` (внутри `CULT`, `RECR`, `TEAM`, `AIBOT`, в `RECR` папки продуктов `RECR-01`…), `B2C` (внутри `VIBE`, в нём папки продуктов `VIBE-01`…). В каждой папке лежит обзор с кодом `-00-00-00-0`.
- Документ `00` описывает уровень целиком: у раздела, у группы.

## Как читать код

- Дивизион задаёт область. `TOTL` общая информация и система, `RECR` продукты для рекрутинга, `VIBE` продукты для сотрудников.
- В `RECR` и `VIBE` раздел это номер продукта.
- В продукте группа это тема. У продуктов `RECR` группа `01` суть, группа `02` процессы, дальше другие группы.
- Документ это элемент группы. Документ `00` описывает уровень целиком: продукт, группу.
- Чанк `0` общая структура документа.

Источник: Максим, сообщение от 03.10.2026, и `context-handoff-2026-10.md`, раздел «Правила нейминга».
