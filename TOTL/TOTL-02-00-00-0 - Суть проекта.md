# TOTL-02-00-00-0 - Суть проекта

## Что это

VibeHunt: predictive talent platform, предиктивная платформа для работы с талантами. Главное обещание: точная диагностика командного вайба.
Вайб: особенности мышления, реакций и поведения каждого участника для достижения командных целей.
Источник: Презентация «VibeHunt для HRD», файл от 30.09.2026, слайд 1.

Предложение: интеллектуальная система оценки потенциала сотрудников. Проверенная методология, автоматизированные процессы, собственные AI и ML модели. Личный консультант это отдельная платная услуга: продукт существует и без неё (Максим, 03.10.2026).
Источник: Презентация «VibeHunt для HRD», файл от 30.09.2026, слайд 2.

Покупатель: HRD компании. Пользователи: HR, руководитель, сотрудник, кандидат. Роли: [роли в сервисе](TOTL-02-01-00-0%20-%20%D0%A0%D0%BE%D0%BB%D0%B8%20%D0%B2%20%D1%81%D0%B5%D1%80%D0%B2%D0%B8%D1%81%D0%B5.md).

## Три направления

| Направление | Результат для клиента | Дивизионы |
|---|---|---|
| Собрать сбалансированную команду | оцифровка статуса динамики команды и готовый план действий | `TEAM` |
| Повысить скорость и точность найма | найм по соответствию профиля кандидата задачам, ценностям компании и руководителя | `CULT`, `RECR`, `VIBE` |
| Улучшить вовлечённость сотрудников | вовлечённость через игровые механики и контроль своего состояния | `WAIBO` |

Источник: Презентация «VibeHunt для HRD», файл от 30.09.2026, слайды 2–5. Раскладка по дивизионам: Максим, 03.10.2026 для `TEAM` и `WAIBO`, остальное предположение.

Продукты `B2B` для компаний: `CULT`, `RECR`, `TEAM`, `WAIBO`. Продукты `B2C` для сотрудников: `VIBE`.
Источник: Максим, 03.10.2026.

## Старт MVP

На старте MVP занимаемся продуктами рекрутинга (`RECR`) и культурного кода (`CULT`) в B2B и вайба (`VIBE`) в B2C. Подробнее: [объём MVP](TOTL-02-07-00-0%20-%20%D0%9E%D0%B1%D1%8A%D1%91%D0%BC%20MVP.md). Источник: Максим, 03.10.2026.

Эффект измеряется в метриках клиента: [метрики эффекта](TOTL-02-05-00-0%20-%20%D0%9C%D0%B5%D1%82%D1%80%D0%B8%D0%BA%D0%B8%20%D1%8D%D1%84%D1%84%D0%B5%D0%BA%D1%82%D0%B0.md). Источник: Презентация «VibeHunt для HRD», файл от 30.09.2026, слайды 2 и 8.
