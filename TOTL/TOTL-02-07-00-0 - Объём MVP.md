# TOTL-02-07-00-0 - Объём MVP

На старте MVP занимаемся продуктами рекрутинга и культурного кода в B2B и вайба в B2C. Источник: Максим, 03.10.2026.

| Дивизион | Папка | В старте MVP |
|---|---|---|
| `RECR` рекрутинг | `B2B/RECR` | да |
| `VIBE` вайб | `B2C/VIBE` | да |
| `CULT` культурный код | `B2B/CULT` | да |
| `TEAM` диагностика команды | `B2B/TEAM` | нет |
| `AIBOT` бот вовлечённости для компаний | `B2B/AIBOT` | нет |
| `WAIBO` колесо баланса, коучинг, стратегии | `B2C/WAIBO` | нет |

Презентация «VibeHunt для HRD» показывает все три направления. MVP уже: входят найм (`RECR`), культурный код компании (`CULT`) и профиль сотрудника (`VIBE`).

## Подтверждено

- Под «вайбом в B2C» входят все `VIBE-01…04`. Максим, 03.10.2026.
- `CULT` входит в старт MVP, поэтому мэтч (`RECR-02`) получает культурный код компании из него. Максим, 03.10.2026.

## Что из этого следует

- Основные усилия, процессы и требования в первую очередь по `RECR-01…06` и `VIBE-01…04`.
- Продукты `TEAM`, `AIBOT`, `WAIBO` описаны только обзорами и в работу не берутся.
- В `CULT` один продукт `CULT-01` Культурный код компании (Максим, 03.10.2026), процесс 1 относится к нему по предположению.
