# TOTL-02-07-00-0 - Объём MVP

На старте MVP занимаемся продуктами рекрутинга в B2B и вайба в B2C. Источник: Максим, 03.10.2026.

| Дивизион | Папка | В старте MVP |
|---|---|---|
| `RECR` рекрутинг | `B2B/RECR` | да |
| `VIBE` вайб | `B2C/VIBE` | да |
| `CULT` культурный код | `B2B/CULT` | нет |
| `TEAM` диагностика команды | `B2B/TEAM` | нет |
| `WAIBO` вовлечённость | `B2B/WAIBO` | нет |

Презентация «VibeHunt для HRD» показывает все три направления. MVP уже: из них входит только направление найма и профиль сотрудника.

## Что из этого следует

- Основные усилия, процессы и требования в первую очередь по `RECR-01…06` и `VIBE-01…04`.
- Продукты `CULT`, `TEAM`, `WAIBO` описаны только обзорами и в работу не берутся.
