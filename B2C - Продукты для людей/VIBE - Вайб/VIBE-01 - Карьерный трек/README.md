## Как читать имена файлов

`VIBE-01-ГГ-ДД-Ч`: продукт, группа, документ, чанк. Номер группы равен номеру шага: группа `01` это шаг 1, группа `06` шаг 6. Документы группы `00` это общие файлы продукта. Полные правила: [REPO-01-01-00-0 Нейминг и структура](../../../REPO%20-%20%D0%9F%D1%80%D0%B0%D0%B2%D0%B8%D0%BB%D0%B0%20%D1%80%D0%B5%D0%BF%D0%BE%D0%B7%D0%B8%D1%82%D0%BE%D1%80%D0%B8%D1%8F/REPO-01%20-%20%D0%9F%D1%80%D0%B0%D0%B2%D0%B8%D0%BB%D0%B0/REPO-01-01-00-0%20-%20%D0%9D%D0%B5%D0%B9%D0%BC%D0%B8%D0%BD%D0%B3%20%D0%B8%20%D1%81%D1%82%D1%80%D1%83%D0%BA%D1%82%D1%83%D1%80%D0%B0.md).

## Шесть шагов продукта

1. Оцифровка резюме
2. Аудит опыта
3. Ответы на вопросы `T-Track`
4. Описание кейсов (можно пропустить, форма на сайте)
5. Грейдинг
6. Скрытая оценка `Big Five` и `Hogan` (при запуске не показывается никому, на этапе проектирования доступна)

Образец результата: аналитический отчёт ARFT-01 (исторический образец в материалах Owner, в репозитории нет).
