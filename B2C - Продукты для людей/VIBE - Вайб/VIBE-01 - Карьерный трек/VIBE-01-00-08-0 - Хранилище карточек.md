В каждом файле строка заголовков и одна демонстрационная строка (вымышленные данные).

1. Скрипт разбирает резюме и записывает рабочую карточку по шаблону (вкладка «Карточки») со статусом «черновик».
2. Человек подтверждает разделы, статус меняется на «подтверждена частично» или «подтверждена полностью».
3. Когда подтверждены обязательные разделы (шапка, 1, 3, 4, 5-9), система проверяет карточку по [схеме данных](VIBE-01-00-05-0%20-%20%D0%A1%D1%85%D0%B5%D0%BC%D0%B0%20%D0%B4%D0%B0%D0%BD%D0%BD%D1%8B%D1%85%20%D0%BA%D0%B0%D1%80%D1%82%D0%BE%D1%87%D0%BA%D0%B8.json), вырезает закрытые поля и создаёт строку в вкладке «Опубликовано» со статусом «действует». Предыдущая версия этого человека получает статус «заменена».
4. Сайт читает только вкладку «Опубликовано», строки со статусом «действует». Рабочие данные сайту недоступны.
5. Отзыв ссылки: строка получает статус «отозвана», её снимок очищается, страница перестаёт открываться. Новая ссылка получает новый случайный адрес.
6. Правка карточки создаёт новую версию: новая строка в «Опубликовано», предыдущая «заменена».

## Вкладка «Опубликовано» (снимки)

Одна строка на версию снимка. Сайт читает эту вкладку.

| Столбец | Что внутри |
|---|---|
| `id` | идентификатор человека, как в «Карточках» |
| `версия` | номер версии снимка |
| `статус` | `действует`, `заменена`, `отозвана`; у человека не больше одной строки со статусом «действует» |
| `адрес` | случайная часть публичного адреса (не имя), создаётся при публикации |
| `опубликовано` | дата и время публикации |
| `отозвано` | дата и время отзыва (пусто, пока не отозвана) |
| `проверка_схемы` | `ok` или текст ошибок |
| `подтвердил` | кто подтвердил (человек) |
| `снимок_json` | публичные данные карточки в виде JSON, без закрытых полей; при отзыве очищается |

## Риски

- В таблице лежат персональные данные людей. До перехода на базу данных доступ нужно ограничить: таблица закрыта, доступ у владельца и сервисного аккаунта скрипта, сайт получает только вкладку «Опубликовано» (отдельным файлом или отдельным доступом). Как именно это сделать: не определено.
- Лимиты и скорость Google Таблицы подходят для проверки на десятках и сотнях карточек, не для нагрузки продакшена.
- Закон о персональных данных (хранение данных граждан, место хранения): юридическая проверка, задача в Notion.
