# LEGACY - Конфиденциальность и видимость данных

Кто что видит и как защищены данные. Источник: Презентация «VibeHunt для HRD», файл от 30.09.2026, слайд 8.

| Правило | Суть |
|---|---|
| eNPS | полностью анонимный, результаты по группам от 8 человек |
| Личный отчёт | видит только сам сотрудник |
| Руководитель и HRD | видят карту команды и рекомендации, без сырых ответов |
| Согласие | письменное согласие каждого сотрудника перед тестами |
| Хранение | данные хранятся на серверах, удаляются по запросу |
