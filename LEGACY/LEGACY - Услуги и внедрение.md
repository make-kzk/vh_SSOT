# LEGACY - Услуги и внедрение

## Услуга: личный консультант

Личный консультант это отдельная услуга. Продукт существует без неё.
Источник: Максим, 03.10.2026. В презентации консультант указан среди предложения (Презентация «VibeHunt для HRD», файл от 30.09.2026, слайд 2).

## Внедрение у клиента

Шесть шагов относятся к услуге, а не к продукту. При этом продукт должен учитывать логику этих шагов (Максим, 03.10.2026).

| Шаг | Что делается | Что должен поддерживать продукт |
|---|---|---|
| 1. Готовим сценарий | согласуем цели, этапы, критерии эффективности и действия | настраиваемый сценарий: цели, этапы, критерии |
| 2. Настраиваем систему | калибровка под нишу и тип компании | калибровка под клиента |
| 3. Интегрируем | выполняем действия в соответствии со сценарием | интеграции по сценарию |
| 4. Адаптируем | промежуточный чек-поинт для обеспечения качества | промежуточная проверка качества |
| 5. Результат | достигаем поставленных задач по целевым метрикам | отслеживание целевых метрик |
| 6. Поддержка | продолжаем поддерживать процессы и архитектуру системы | поддержка процессов после внедрения |

Параметры: нагрузка до 4 часов от каждого сотрудника за весь проект, около 3 недель от старта до готового результата, 3 месяца поддержки после подтверждения результата.
Источник шагов и параметров: Презентация «VibeHunt для HRD», файл от 30.09.2026, слайд 7. Колонка «Что должен поддерживать продукт» выведена из требования Максима и не подтверждена.
