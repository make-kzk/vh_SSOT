# ARCH-00-00-02-0 - Состав системы

**Статус содержания.**
- Подтверждено Owner: состав системы (сервис, база данных, интеграции, три интерфейса), состав и назначение админки, граница между продуктами и архитектурой.
- Предположение агента: нет.
- Не определено: технологии, провайдеры, схема данных, права доступа, хранение записей и персональных данных, формат интеграции с HeadHunter, использование скиллов и вебхуков по шагам.

Решение Owner, 05.10.2026: архитектура реализации описывается здесь отдельно от продуктов. Продукты (`VIBE`, `RECR`, `TEAM`, `WAIBO`, `AIBOT`) описывают, что система делает для человека. Этот документ описывает, из чего она собрана. Сначала фиксируется состав и интеграции без выбора технологий.

## Составные части

| Часть | Что это |
|---|---|
| Сервис | серверная часть, в которой работают продукты |
| База данных | профили, вакансии, оценки, результаты тестов, согласия; карточки людей `VIBE-01` для старта хранятся в Google Таблице, затем в базе данных (Решение Owner, 05.10.2026) |
| LLM API | подключение языковой модели для рекомендаций, транскриптов и отчётов |
| HeadHunter API | интеграция с внешним сайтом вакансий |
| Вебхуки и скиллы | связки с внешними сервисами и автоматизация шагов |
| Видеоинтервью | встреча в Zoom, запись, транскрибация (Решение Owner, 05.10.2026, см. ## Три интерфейса

| Интерфейс | Кто работает | Что делает |
|---|---|---|
| Кандидат | кандидат, сотрудник | тесты `VIBE`, резюме и кейсы, отклик на вакансию, чат-бот, участие в видеоинтервью, согласия |
| Компания | рекрутёр, нанимающий менеджер, директор подразделения, HRD | вакансия, топ-10, бланки и оценки интервью, отчёт `RECR-07`, оффер, замеры адаптации, код команды |
| Админка | команда VibeHunt | клиенты и вакансии; оплата по шагам 1-3 и решения Owner по форс-мажору; метрики MVP с порогами и сигналами; согласия, вопросы и нормы тестов |

Не определено: отдельные интерфейсы для HRBP и собственника бизнеса клиента.
