## Решение на этапах интервью

Решение Owner, 04.10.2026: решение по кандидату принимается на каждом этапе интервью (`RECR-03` … `RECR-06`), а не один раз в конце. Варианты на каждом этапе одни и те же: оффер, следующий этап, резерв, отклонить. «Оффер» на этапе означает остановить интервью и перейти к офферу.

Шаги интервью обязательны по умолчанию, но решение «оффер» на любом этапе завершает интервью досрочно, остальные шаги не проводятся. Остальные решения («следующий этап», «резерв», «отклонить») ведут себя как обычно. Решение Owner, 04.10.2026. Предиктивный отчёт `RECR-07` при этом строится по пройденным этапам, пропуски указываются, уверенность прогноза понижена. Решение Owner, 05.10.2026.

Кто принимает решение на этапе (Решение Owner, 04.10.2026): тот, кто провёл этап, на основании своей оценки по бланку.

| Этап | Кто принимает решение |
|---|---|
| `RECR-03` интервью с рекрутёром | рекрутёр |
| `RECR-04` интервью с менеджером | нанимающий менеджер |
| `RECR-05` тестовое задание | нанимающий менеджер |
| `RECR-06` интервью с директором | директор подразделения |

Решение «оффер» на этапе запускает `RECR-08`: условия утверждает нанимающий менеджер, и оффер кандидату не отправляется до этого утверждения. Так «оффер» рекрутёра на `RECR-03` не обходит менеджера. Прежнее правило «окончательное решение принимает рекрутёр» заменено этой таблицей.

Метрика совпадения решения продукта с решением человека считается отдельно по каждому этапу, порог 10% (Решение Owner, 04.10.2026).

Данные интервью (Решение Owner, 05.10.2026): интервью `RECR-03`, `RECR-04` и `RECR-06` проходят в Zoom, система записывает встречу и транскрибирует её. Интервьюер вносит оценки и решение по бланку в систему. Если записи нет, источником данных остаётся только оценка интервьюера. Кандидат даёт явное согласие на запись перед интервью, без согласия записи нет (Решение Owner, 05.10.2026, раздел «Сквозные требования»).

Решение продукта на этапе (Решение Owner, 05.10.2026): продукт даёт рекомендацию по тому же бланку, что и человек. Вход: профиль вакансии, профиль кандидата из `VIBE`, материалы этапа (транскрипт интервью, если запись есть, тестовое задание). Продукт ставит предварительные оценки по шкале 1-3-7-13-21 и предлагает решение (оффер, следующий этап, резерв, отклонить). Человек принимает своё решение независимо, система сравнивает. Как продукт считает оценки: не определено до разработки.

Правило принятия решения хранится в этом обзоре, в `RECR-03` … `RECR-06` короткий раздел «Решение на этапе» со ссылкой сюда (Решение Owner, 04.10.2026).

Дивизион `RECR` соответствует направлению «Повысить скорость и точность найма»: найм по соответствию профиля кандидата задачам, ценностям компании и руководителя.
Источник: презентация для HRD (материал Owner, не входит в репозиторий), слайд 4.
