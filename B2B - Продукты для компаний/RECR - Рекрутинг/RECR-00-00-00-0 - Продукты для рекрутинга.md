# RECR-00-00-00-0 - Продукты для рекрутинга

Назначение папки: даёт общую картину продуктов рекрутинг. Дивизион `RECR`: продукты для рекрутинга, то есть для компаний. Папка каждого продукта `RECR-0N` даёт точную картину этого продукта. Номер раздела это номер продукта.
Источник: Owner, сообщение от 03.10.2026.

## Направление в презентации

Дивизион `RECR` соответствует направлению «Повысить скорость и точность найма»: найм по соответствию профиля кандидата задачам, ценностям компании и руководителя.
Источник: презентация для HRD (материал Owner, не входит в репозиторий), слайд 4.

| Функция в презентации | Продукт, предположение |
|---|---|
| Архитектура позиции: карьерный трек, навыки, culture fit | `RECR-01`, `TEAM-01` |
| Автоматизация рутины: адженда, фиксация, аналитика | `RECR-03` |
| Прогноз результативности: соответствие, риски, возможности | `RECR-04` |
| Общий статус воронки: все вакансии и этапы найма | не определено |

Соответствие предположение, не подтверждено.
