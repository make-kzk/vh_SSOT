# RECR-03-01-00-0 - Подготовка вопросов

Решение Owner, 03.10.2026: группа 01 продукта `RECR-03`, подготовка вопросов.
Источник: страница Notion «Вопросы для интервью (Key Logic & Principles of Question Preparation)», МАСТЕР БАЗА КАНДИДАТОВ. Описание шагов Предположение, не подтверждено. Отнесение шагов к группам Предположение.

## Шаги группы

Выход каждого шага входит в следующий.

| Шаг | Вход | Выход |
|---|---|---|
| Карта компетенций | резюме, сопроводительное письмо, вакансия | таблица: кластер, компетенция, уровень по резюме, факты из резюме, что проверить |
| Вопросы для интервью | карта компетенций, вакансия | блоки вопросов с уточняющими, метод STAR, фокус проверки |

Выход группы идёт в группу 02 (оценка) и в группу 03 (фокусы проверки для задания).

## Критерии качества

- Карта: каждый вывод опирается на текст резюме, заявленное отделено от подтверждённого.
- Вопросы: только о прошлом опыте, каждый привязан к достижению из резюме.
