**Статус содержания.**

## Как читать

- Девять продуктов в порядке найма, фиолетовые пунктирные стрелки между ними показывают порядок.
- Серая стрелка: вход от человека. Зелёная: выход к человеку. Фиолетовая пунктирная: передача между продуктами и направлениями.
- Внешние входы: профиль вайба из `VIBE`, культурный код команды из `TEAM-01`.

## Люди и продукты

| Продукт | Вход (от роли) | Выход (к роли) |
|---|---|---|
| `RECR-01` вакансия | Рекрутёр: описание вакансии, ответы на опросник | профиль вакансии |
| `RECR-02` подбор | нет | Рекрутёр: топ10 кандидатов |
| `RECR-03` интервью рекрутёра | Рекрутёр: оценка интервью | Рекрутёр: бланк |
| `RECR-04` интервью менеджера | Нанимающий менеджер: оценки по своему бланку | не определён |
| `RECR-05` тестовое задание | Кандидат: выполненное задание | не определён |
| `RECR-06` интервью директора | Директор: интервью и оценка | Рекрутёр: итоговое решение |
| `RECR-07` прогноз | Нанимающий менеджер: оценка точности отчёта | Нанимающий менеджер: отчёт о прогнозе |
| `RECR-08` оффер | Нанимающий менеджер: утверждение условий | Рекрутёр: оффер для отправки; Кандидат получает оффер от Рекрутёра |
| `RECR-09` адаптация | Нанимающий менеджер: оценки через 7, 14, 28, 60 и 90 дней; Сотрудник: информация через те же дни | Нанимающий менеджер: план адаптации |

Коммуникация Рекрутёра и Кандидата идёт через систему (чат-бот): оффер отправляется через чат-бот, ответы и правки условий от Кандидата поступают тем же путём. Решение Owner, 04.10.2026.
